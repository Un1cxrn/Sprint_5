 Финальный проект 5 спринта (Яндекс.Самокат)

Проект содержит автотесты на Selenium для учебного сервиса «Яндекс.Самокат». 
В рамках проекта реализовано тестирование регистрации, авторизации, личного кабинета и конструктора бургеров.

 Структура проекта
    conftest.py — фикстуры (запуск браузера, регистрация пользователя).
    helpers.py — генераторы email и пароля.
    locators.py — описание локаторов с комментариями (Page Object).
    tests — директория с тестами:
        test_registration.py — тесты регистрации.
        test_login.py — тесты авторизации (4 точки входа).
        test_account.py — тесты личного кабинета и выхода.
        test_constructor.py — тесты переключения вкладок конструктора.
